# Governance

Parallax is currently a maintainer-led project. Probal Bose is the initial
maintainer and release manager.

Maintainers review contributions for correctness, reproducibility, scope,
licensing, and community impact. Routine changes merge after passing required
checks and one maintainer approval. Changes to public schemas, measurement
methodology, licences, security policy, or release process require an issue or
proposal that documents the motivation and migration path.

Decisions are made openly in issues and pull requests where practical. For a
substantive disagreement, the maintainer records the decision and rationale.
As the contributor base grows, this document will be updated to add maintainers
and a lightweight voting process.

The maintainer may edit or remove contributions that violate the Code of
Conduct, introduce legal risk, or cannot be validated.
