# Security policy

Please do not report vulnerabilities in public issues or discussions. Email a
minimal reproduction and impact assessment to **probos22@gmail.com** with the
subject `Parallax security report`.

We aim to acknowledge a report within 7 days and will coordinate a fix and
disclosure timeline with the reporter. Supported versions are the latest tagged
release and the `main` branch.

Do not include secrets, model weights, private datasets, or customer data in a
report. If your finding concerns a third-party model or dependency, include the
exact version and upstream advisory when available.
